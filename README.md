# MOONFALL · 달빛의 생존자

자동 전투, 무기 진화, 보스전과 영구 성장이 있는 독립 서바이벌 웹 게임입니다.

## 플레이
- PC: WASD / 방향키. Esc 또는 P로 일시정지.
- 모바일: 화면을 드래그해서 이동합니다. 공격은 자동입니다.
- 경험치 보석으로 레벨업하고 무기 레벨 5에서 진화합니다.
- 6분 이상 생존하고 마지막 보스를 처치하면 승리합니다.
- 기록과 재화는 각 기기의 브라우저에 저장됩니다.

## 설치
HTTPS 게임 주소를 Android Chrome 또는 iPhone Safari로 열어 홈 화면에 추가하세요. 첫 실행 후 게임 리소스가 저장되면 오프라인 플레이가 가능합니다.

## 호스팅
빌드나 서버가 필요 없는 정적 사이트입니다. GitHub Pages에서 main 브랜치의 루트 폴더를 배포 대상으로 선택할 수 있습니다. `.nojekyll`을 포함합니다. 유료 API, 외부 런타임, 광고, 결제 및 분석 추적을 사용하지 않습니다.
