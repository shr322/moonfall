# Verdant Volley · 초록빛 화살

Arrow a Row의 자동 사격, 좌우 이동, 강화 선택에서 착안한 독립적인 3D 브라우저 게임입니다. 원작과 동일한 완제품 복제본은 아니며, 원작의 코드·상표 디자인·캐릭터·음악을 사용하지 않았습니다.

## 바로 실행

가장 간단한 실행 방법: 함께 제공한 **Verdant-Volley.html** 한 파일을 Chrome 또는 Edge에서 엽니다. 이 파일은 코드와 에셋을 모두 내장합니다.

소스 폴더를 사용할 경우:

1. ZIP 파일을 내려받았다면 **폴더 전체를 압축 해제**합니다.
2. `index.html`을 Chrome 또는 Edge로 엽니다.
3. **모험 시작**을 누릅니다.

설치, 서버, 로그인, API 키, 인터넷 연결, 결제가 필요하지 않습니다. Three.js와 모든 에셋을 함께 제공하므로 파일을 직접 열어 실행할 수 있습니다. WebGL을 지원하는 브라우저가 필요합니다.

## 조작과 규칙

- 이동: **A / D**, **← / →**, 또는 화면 드래그. 터치 화면에서는 좌우 버튼도 사용할 수 있습니다.
- 달리기와 화살 발사는 자동입니다. 좌우 이동으로 화살을 적에게 맞추세요.
- 두 강화 게이트 중 원하는 쪽으로 통과하면 그 강화를 얻습니다.
- 코인은 자동으로 수집됩니다. 물리적 적과 바위, 적의 탄막은 피하세요.
- **Esc / P**: 일시정지. 다른 창으로 전환할 때도 자동으로 일시정지됩니다.
- 우측 상단 소리 버튼: 합성 효과음과 배경 선율 켜기/끄기. 처음에는 음소거입니다.
- 750m 지점의 보스에게 세 공격 단계가 있습니다. 처치 후 무한 모드로 계속할 수 있습니다.
- 작업실에서 게임 내 코인으로 공격력, 체력, 코인 획득량을 영구 강화할 수 있습니다. 실제 결제 기능은 없습니다.

## 저장

브라우저 localStorage에 코인, 최고 거리, 모험 횟수, 보스 처치 횟수, 영구 강화, 소리 설정을 저장합니다. 실행 중인 모험 자체를 이어서 불러오는 기능은 없습니다. 브라우저 데이터 삭제·시크릿 모드·파일 위치/브라우저 변경 시 저장 데이터가 사라지거나 별도의 기록으로 시작할 수 있습니다.

## 검증 범위

- 게임 로직: 발사·충돌·게이트·강화·피해·패배/재시작·보스 3단계·승리·무한 모드. 고정 시드 자동 플레이로 167초에 보스 처치.
- UI/저장 통합: 12개 자동 검증 통과(구매, 영구 강화, 중복 코인 방지, 일시정지, 키보드, 창 전환, 승리, 무한 모드, 저장 등).
- 브라우저: 단일 HTML을 로컬 HTTP로 실행하여 1280×720 및 390×844 화면과 키보드·터치 버튼·게이트·일시정지/복귀 확인. 콘솔 오류 없음.
- 도구 보안 정책상 file:// 직접 열기는 검사하지 못했습니다. 모든 실행 리소스는 HTML에 내장되어 있으며 외부 파일을 읽지 않습니다.
